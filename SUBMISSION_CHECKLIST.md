# 🚀 GUVI Hackathon Submission Checklist

## Pre-Submission Verification (Complete Before Submitting)

### ✅ 1. Core Functionality

- [ ] **API is deployed** to a public URL (not localhost)
- [ ] **Health check works**: `curl https://your-api.com/health` returns 200
- [ ] **API Key authentication** is working correctly
- [ ] **Response format** matches specification: `{"status": "success", "reply": "..."}`
- [ ] **Final callback** includes all required fields (sessionId, scamDetected, extractedIntelligence, etc.)

### ✅ 2. Code Quality & Requirements

- [ ] **No hardcoded responses** - All responses generated by AI
- [ ] **No test code** in production endpoints
- [ ] **Error handling** for all LLM API failures
- [ ] **Timeout compliance** - Responses within 20 seconds (to avoid 30s evaluation timeout)
- [ ] **Valid API keys** - All keys in .env are working (test with separate script)

### ✅ 3. Scoring Optimization

#### Scam Detection (20 points)

- [ ] AI model configured correctly (Gemini/Claude/GPT-4)
- [ ] Returns `scamDetected: true` for actual scam scenarios
- [ ] No false positives on legitimate messages
- [ ] Confidence threshold set to 0.5 or lower for high sensitivity

#### Intelligence Extraction (40 points - 10 points each)

- [ ] **Bank Account extraction** working (regex pattern: 9-18 digits)
- [ ] **UPI ID extraction** working (pattern: `user@paytm`, `user@phonepe`, etc.)
- [ ] **Phone Number extraction** working (10-15 digits with optional +)
- [ ] **Phishing Links extraction** working (all HTTP/HTTPS URLs)
- [ ] All extraction patterns tested with `test_scenarios.json`

#### Engagement Quality (20 points)

- [ ] Conversations last **2+ minutes** (target: 2-5 minutes)
- [ ] Conversations have **6+ message exchanges** (target: 6-10 messages)
- [ ] Agent responses are natural and human-like
- [ ] Agent adapts to scammer's approach (personas working)
- [ ] Session doesn't end prematurely

#### Response Structure (20 points)

- [ ] `sessionId` field present
- [ ] `scamDetected` boolean present
- [ ] `extractedIntelligence` object with 5 fields (phoneNumbers, bankAccounts, upiIds, phishingLinks, emailAddresses)
- [ ] `engagementMetrics` object with conversationDuration and messageCount
- [ ] `agentNotes` field present
- [ ] All fields match evaluation specification exactly

### ✅ 4. Testing & Validation

- [ ] Run `python self_test.py` and get score **>70** (preferably >85)
- [ ] Test with all 6 scenarios in `test_scenarios.json`
- [ ] Test with production URL (not localhost)
- [ ] Verify final callback is sent to GUVI endpoint
- [ ] Check logs for any errors or warnings

### ✅ 5. GitHub Repository

- [ ] Repository is **public** or accessible to evaluators
- [ ] **README.md** is complete with:
  - Project overview
  - Setup instructions
  - API documentation
  - Testing instructions
  - Tech stack
  - Hackathon scoring details
- [ ] **.env.example** file provided (no real API keys)
- [ ] **requirements.txt** has all dependencies
- [ ] Code is clean and well-commented
- [ ] No sensitive information (API keys) in repository

### ✅ 6. Deployment Configuration

- [ ] Environment variables set correctly on hosting platform
- [ ] `LLM_PROVIDER` set to working provider (gemini/anthropic/openai)
- [ ] `GEMINI_MODEL` set to valid model: **gemini-2.5-flash** (not gemini-2.0-flash-exp)
- [ ] Multiple API keys configured for rate limit handling
- [ ] `GUVI_CALLBACK_URL` set to: `https://hackathon.guvi.in/api/updateHoneyPotFinalResult`
- [ ] Logs are accessible for debugging

### Excellent Submission (95+ points)

- [ ] Scam Detection: 20/20 (perfect detection)

## 🔍 Common Issues to Avoid

### ❌ Configuration Issues

- [ ] Invalid Gemini model name (use gemini-2.5-flash, not gemini-2.0-flash-exp)
- [ ] Expired or invalid API keys
- [ ] Wrong LLM provider selected

### ❌ Response Format Issues

- [ ] Missing "status" field
- [ ] Missing "reply" field
- [ ] Wrong field names in final callback
- [ ] Missing required intelligence fields

### ❌ Functionality Issues

- [ ] Responses timeout (>20 seconds)
- [ ] Agent doesn't engage scammers naturally
- [ ] Intelligence extraction patterns too strict
- [ ] Session ends too early (<6 messages)

### ❌ Repository Issues

- [ ] API keys exposed in .env file
- [ ] README missing or incomplete
- [ ] .env.example not provided
- [ ] Repository is private
